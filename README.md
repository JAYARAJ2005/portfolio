# Jayaraj S | Personal Portfolio

A responsive, dark-themed personal portfolio website with animated sections and a custom cursor.

**Live site:** https://jayaraj-portfolio.vercel.app

## About

I'm Jayaraj S, an MCA student and aspiring Full Stack Developer based in Chennai, India. This portfolio showcases my projects, skills, education, certifications and resume.

## Features

- Dark, modern design that works on desktop and mobile
- Animated hero with a typing effect and a scrolling skills banner
- Custom cursor, magnetic buttons and scroll-reveal animations
- Sections for About, Experience and Education, Skills, Projects and Certifications
- Project cards with live demo and GitHub links
- Downloadable resume (PDF)
- Contact form that opens the visitor's email app

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Deployed on Vercel, with source hosted on GitHub

## Run Locally

```bash
git clone https://github.com/JAYARAJ2005/portfolio.git
cd portfolio
```

Then open `index.html` in your browser. No installation or build step is needed.
